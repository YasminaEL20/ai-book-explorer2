# AI Book Explorer

AI Book Explorer est une application web permettant de rechercher des livres via Google Books API et d'afficher des visualisations (Timeline, Top Authors) via Chart.js.

## Installation
- Cloner le repo
- Ouvrir le projet dans VS Code
- Installer l'extension **Live Server**
- Faire clic-droit sur `index.html` → **Open with Live Server**
